# HomeworkAI v2

Современный сервис для домашнего задания: аккаунты с Telegram-проверкой, ручная модерация, планы, ChatGPT/Gemini, AI-поддержка DeepSeek, учебники/RAG, админская и менеджерская панели и Telegram-бот `/dz`.

## Стек

- Node.js 20+
- Express 5
- Supabase Postgres
- Cookie + JWT авторизация
- OpenAI Responses API для ChatGPT
- Google Gemini API
- DeepSeek API
- Telegram Bot API через HTTPS webhook
- Vanilla HTML/CSS/JS frontend без сборщика

Ключи AI остаются только на сервере в `.env`; клиентский JavaScript их не получает.

## 1. Установка

Установи Node.js 20 или новее.

```bash
npm install
npm start
```

Для разработки:

```bash
npm run dev
```

Локально сайт будет на `http://localhost:3000`.

## 2. Supabase

Создай проект в Supabase, открой **SQL Editor**, вставь целиком `schema.sql` и выполни.

Схема создаёт:

- users
- telegram_links
- telegram_verifications
- homework
- announcements
- textbook_chunks + vector embedding
- ai_solutions
- ai_chat_messages
- support_chats
- support_messages
- deletion_requests
- registration_requests
- plan_requests
- service_settings
- faq
- функцию `match_textbook_chunks`

На Supabase должен быть доступен extension `vector`.

## 3. Переменные окружения

Скопируй `.env.example` в `.env`.

Минимально нужно заполнить:

```env
APP_URL=http://localhost:3000
JWT_SECRET=очень-длинный-случайный-ключ
SUPABASE_URL=https://...
SUPABASE_SERVICE_ROLE_KEY=...
ADMIN_USERNAME=Admin
ADMIN_PASSWORD=...
```

Для AI:

```env
OPENAI_API_KEY=...
OPENAI_MODEL=gpt-5
OPENAI_EMBEDDING_MODEL=text-embedding-3-small

GEMINI_API_KEY=...
GEMINI_MODEL=gemini-3.7-flash

DEEPSEEK_API_KEY=...
DEEPSEEK_MODEL=deepseek-chat
DEEPSEEK_BASE_URL=https://api.deepseek.com
```

Для Telegram:

```env
TELEGRAM_BOT_TOKEN=...
TELEGRAM_WEBHOOK_SECRET=сложный-секрет
TELEGRAM_WEBHOOK_PATH=/telegram/webhook
```

## 4. Telegram

Бот использует webhook, поэтому на Render нужен HTTPS.

После первого деплоя открой админскую панель и используй настройку Telegram webhook либо вызови:

```text
GET /api/admin/telegram/setup
```

Endpoint защищён авторизацией администратора.

### Регистрация

Пользователь сначала пишет боту `/start` в личке. Сервер запоминает его Telegram username и chat id.

После этого на первом шаге регистрации пользователь вводит тот же username. Сервер генерирует шестизначный код на 5 минут и отправляет его в Telegram.

### Команда /dz

В личной переписке или группе:

```text
/dz
```

Бот отправляет всё текущее домашнее задание.

Если сервис остановлен администратором, бот не выдаёт ДЗ и пишет:

```text
Сервис остановлен

<причина>
```

## 5. Пользовательские статусы

После регистрации аккаунт получает `pending`.

Пока администрация не одобрит аккаунт, вход работает, но сервис недоступен.

Решения:

- `approve` → пользователь получает доступ
- `reject` → аккаунт становится `blocked`

При входе не выполняется отдельная блокировка по статусу: пользователь всегда аутентифицируется, а интерфейс уже показывает правильное состояние аккаунта.

## 6. Планы

| План | Цена | AI | Лимит |
|---|---:|---|---|
| Start | 25 ★ | ChatGPT | 5 сообщений / 12 ч |
| Plus | 50 ★ | ChatGPT + Gemini | 10 сообщений / 12 ч |
| Pro | 100 ★ | ChatGPT + Gemini | без лимита |

Каждый выданный платный план действует 7 дней.

Оплата сделана как ручной процесс: пользователь создаёт запрос, а администратор после проверки вручную выдаёт план и срок.

## 7. Учебники и RAG

Администратор может открыть **Учебники** и вставить текст учебника.

Система:

1. разбивает текст на чанки;
2. сохраняет их в Supabase;
3. при наличии OpenAI ключа создаёт embeddings;
4. при решении задания сначала ищет подходящие фрагменты;
5. передаёт найденный контекст AI.

Если embeddings ещё не созданы или OpenAI недоступен, используется запасной поиск по ключевым словам.

## 8. Поддержка

У каждого пользователя один открытый чат поддержки.

Сначала работает DeepSeek.

AI получает FAQ из базы и должен переключаться на человека, если вопрос требует админских действий, связан с оплатой, аккаунтом, модерацией, удалением, блокировкой, планом или AI не уверен в ответе.

После вызова человека поле поддержки остаётся рабочим, но AI больше не отвечает.

Администратор видит:

- пользователя;
- сообщения пользователя;
- сообщения AI;
- сообщения человека;
- пометку `НУЖЕН ЧЕЛОВЕК`;
- возможность ответить;
- возможность закрыть чат.

Закрытие удаляет чат вместе с его сообщениями.

## 9. Хранение

- AI-чат пользователя: 24 часа
- решения AI: 24 часа
- support-chat: удаляется после 24 часов без активности
- announcements: удаляются после истечения срока
- Telegram-коды: 5 минут

Очистка выполняется автоматически на сервере.

## 10. Админская панель

Администратор получает:

- статистику;
- список пользователей;
- поиск по нику и Telegram;
- блокировку/разблокировку;
- назначение/снятие менеджера;
- удаление аккаунта;
- ручную выдачу/снятие плана;
- срок плана;
- запросы регистрации;
- запросы удаления;
- запросы планов;
- поддержку;
- текущие ДЗ;
- оповещения;
- импорт учебников;
- embeddings;
- FAQ;
- остановку сервиса;
- Telegram webhook setup.

## 11. Панель менеджера

Менеджер может только:

- изменять текущее ДЗ;
- создавать оповещения на 12 часов.

Все остальные административные действия защищены ролью `admin`.

## 12. Render

Создай Web Service на Render.

Build Command:

```text
npm install
```

Start Command:

```text
npm start
```

Добавь все значения `.env` в **Environment Variables** Render.

Очень важно: `APP_URL` должен содержать реальный HTTPS URL Render или твоего домена.

Для production:

```env
NODE_ENV=production
COOKIE_SECURE=true
```

## 13. Важные замечания

`SUPABASE_SERVICE_ROLE_KEY` нельзя вставлять во frontend. Он используется только сервером.

Админский пароль также находится только в `.env`.

Для production после первичной установки обязательно поменяй `JWT_SECRET`, `ADMIN_PASSWORD` и `TELEGRAM_WEBHOOK_SECRET`.

## 14. Быстрый тест после запуска

1. Запусти SQL.
2. Запусти сервер.
3. Проверь `GET /api/health`.
4. Открой сайт.
5. Запусти Telegram-бота `/start`.
6. Создай тестовый аккаунт.
7. В админке одобри регистрацию.
8. Выдай Start.
9. Задай AI-вопрос.
10. Добавь ДЗ и проверь решение.
11. Добавь FAQ и проверь поддержку.
12. Проверь `/dz` в группе.
13. Включи остановку сервиса и проверь сайт и бота.
